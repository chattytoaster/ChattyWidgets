# ✦ ChattyWidgets — Движок виджетов для Windows (.NET 8)

**ChattyWidgets** — производительный и ультра-легковесный движок виджетов для рабочего стола Windows с поддержкой нативных (XAML/C#) и веб-виджетов (HTML5/CSS3/JavaScript), встроенным магазином виджетов и форматом пакетов **`.chw`**.

---

## 🚀 Основные возможности

- **Минимальное потребление ресурсов**:
  - Нативные виджеты (XAML): ~**20–25 МБ RAM**, **0% нагрузки на CPU** в фоне.
  - Веб-виджеты (WebView2): ~**60–80 МБ RAM**, поддержка современных стилей (Glassmorphism, неоморфизм, CSS animations, Canvas).
- **Интеграция с рабочим столом (Rainmeter-style)**:
  - Режим «Рабочий стол»: виджет встраивается в подложку рабочего стола (`WorkerW` / `Progman`) под всеми окнами и не исчезает при нажатии `Win + D` («Показать рабочий стол»).
  - Плавающий режим (обычное окно) и режим «Поверх всех окон» (Always on top).
  - Режим «Клик насквозь» (`WS_EX_TRANSPARENT`) — сквозь виджет можно кликать по иконкам рабочего стола или другим окнам.
  - Автоматическое прилипание к краям мониторов и сетке.
- **Магазин виджетов (Store)**:
  - Каталог виджетов с возможностью установки в 1 клик.
  - **Drag & Drop**: перетащите любой файл `.chw` прямо в окно магазина или хаба для мгновенной установки.
  - Поддержка внешних каталогов (JSON / GitHub).
- **Пакеты виджетов `.chw`**:
  - Единый контейнер (zip-архив) с `manifest.json` и ресурсами.
  - Автоматическая ассоциация расширения `.chw` в реестре Windows (двойной клик по файлу запускает установку).
- **Мастерская разработчика (Workshop)**:
  - Создание нового проекта виджета из шаблона в 1 клик.
  - Поддержка горячей перезагрузки (Live Reload) при сохранении исходного кода.
  - Встроенный сборщик в формат `.chw` с валидацией манифеста.
- **Системный трей (System Tray)**:
  - Управление активными виджетами по правому клику мыши на иконку в трее.
  - Быстрое скрытие / сворачивание в трей без закрытия виджетов.

## 📦 Стартовый набор виджетов из коробки

В папке `packages/` и при первом запуске доступны 5 готовых решений:

1. **`com.chatty.clock-glass.chw` (Стеклянные Часы)** — стиль Glassmorphism с блюром, датой на русском языке и мини-индикатором нагрузки CPU.
2. **`com.chatty.system-gauges.chw` (Датчики Ресурсов)** — нативный XAML виджет с круговыми/полосовыми датчиками CPU, RAM, SSD и скорости сети.
3. **`com.chatty.music-player.chw` (Мини-Медиаплеер)** — стильный контроллер для управления Spotify, Яндекс.Музыкой, YouTube и браузером (Play/Pause, Next, Prev, Volume).
4. **`com.chatty.sticky-notes.chw` (Быстрые Заметки / ToDo)** — чек-лист задач и стикер для заметок с постоянным сохранением состояния.
5. **`com.chatty.crypto-tracker.chw` (Курсы Валют и Крипты)** — котировки Bitcoin, Ethereum, TON, а также курсы доллара и евро с автообновлением.

## 🛠 Запуск приложения

```bash
# Сборка проекта
dotnet build

# Запуск Хаба ChattyWidgets
dotnet run

# Запуск встроенного самотестирования движка
dotnet run -- --test
```

После запуска в панели задач рядом с часами появится значок ChattyWidgets, а на экране откроется главное окно Хаба.

## 📝 Спецификация пакета `.chw`

Файл `.chw` — это стандартный zip-архив, содержащий в корне `manifest.json`:

```json
{
  "id": "com.myname.cool-widget",
  "name": "Мой Виджет",
  "version": "1.0.0",
  "author": "Имя Разработчика",
  "description": "Описание виджета",
  "type": "web",                  // "web" или "native"
  "entry": "index.html",           // для web: index.html; для native: Widget.xaml
  "defaultWidth": 300,
  "defaultHeight": 200,
  "minWidth": 150,
  "minHeight": 100,
  "resizable": true,
  "defaultLayer": "desktop",       // "desktop" | "normal" | "top"
  "clickThrough": false,
  "permissions": ["system", "storage", "media"]
}
```

## 🌐 JavaScript API Bridge (`window.chatty`)

Для веб-виджетов движок автоматически внедряет объект `window.chatty`:

### 1. Системные метрики
- `chatty.getCpu()` — текущая загрузка процессора (%).
- `chatty.getMemoryPercent()` — процент занятой памяти (RAM %).
- `chatty.getMemoryUsed()` — занято памяти в ГБ.
- `chatty.getMemoryTotal()` — всего физической памяти в ГБ.
- `chatty.getDiskPercent()` — процент заполнения системного диска.
- `chatty.getDiskFree()` — свободно на диске (ГБ).
- `chatty.getNetDownload()` — скорость загрузки сети (КБ/с).
- `chatty.getNetUpload()` — скорость отдачи сети (КБ/с).
- `chatty.getSystemMetricsJson()` — все метрики одним JSON-объектом.

### 2. Управление мультимедиа
- `chatty.playPause()` — переключение воспроизведения (Play / Pause).
- `chatty.nextTrack()` — следующий трек.
- `chatty.prevTrack()` — предыдущий трек.
- `chatty.volumeUp()` / `chatty.volumeDown()` — регулировка системной громкости.

### 3. Постоянное хранилище (Storage)
- `chatty.storageGet(key, defaultValue)` — получить сохраненное значение по ключу.
- `chatty.storageSet(key, value)` — сохранить значение (сохраняется в `storage.json` виджета).
- `chatty.storageRemove(key)` — удалить ключ.

### 4. Управление окном виджета
- `chatty.closeWidget()` — закрыть виджет.
- `chatty.setLayer("desktop" | "normal" | "top")` — переключить слой окна.
- `chatty.setClickThrough(true | false)` — включить/выключить клик насквозь.
- `chatty.setOpacity(0.1 .. 1.0)` — изменить прозрачность.

## 💡 Создание собственного виджета за 3 шага

1. Откройте в приложении вкладку **🛠 Мастерская**.
2. Введите название виджета, выберите тип (**Web** или **Native**) и нажмите **«Создать каркас проекта»**.
3. Отредактируйте файлы `index.html` или `Widget.xaml` в вашей любимой IDE, затем нажмите **«Собрать пакет .chw»** — готовый файл можно отправлять друзьям или загружать в магазин!
