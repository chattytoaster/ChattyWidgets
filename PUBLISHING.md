## 🛡 Архитектура доверия и подписи

В экосистеме ChattyWidgets действует строгая трёхуровневая модель безопасности:

```
[Официальный ключ разработчика] ──(RSA PKCS1v15 + SHA256)──► [✦ Официальный виджет]
[PR от проверенного GitHub-автора] ──(GitHub Actions Check)──► [✓ @username (GitHub)]
[Сторонний файл с сайта/форума] ───────────────────────────► [⚠ Сторонний виджет]
[Неподписанный файл с именем com.chatty.*] ───────────────► [⛔ Фальсификация (Блокировка)]
```

### Ключи шифрования
- **Публичный ключ (Public Key)**:
  Вшит непосредственно в исходный код клиента:
  [`Core/Services/SecurityService.cs`](Core/Services/SecurityService.cs)
  Он используется приложением для мгновенной проверки подлинности официальных виджетов даже при работе офлайн.
- **Закрытый ключ (Private Key)**:
  Хранится локально в `ChattyWidgetsLibrary/keys/official_private.pem` и защищён файлом `.gitignore`.
  Для автоматической сборки в GitHub Actions он добавляется в **Settings → Secrets and variables → Actions** репозитория под именем `OFFICIAL_PRIVATE_KEY`.

## 📦 Релиз новой версии приложения ChattyWidgets

### 1. Подготовка сборки
Перед выпуском релиза убедитесь, что все тесты проходят:
```bash
dotnet test
dotnet run -- --test
```

### 2. Компиляция стабильного бинарника
Для сборки единого автономного исполняемого файла (Single File EXE) под Windows x64 выполните:
```bash
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true
```
Скомпилированный файл будет находиться в каталоге:
`bin/Release/net8.0-windows10.0.19041.0/win-x64/publish/ChattyWidgets.exe`

### 3. Создание релиза на GitHub
1. Перейдите в репозиторий: `https://github.com/chattytoaster/ChattyWidgets/releases`.
2. Нажмите **Draft a new release**.
3. Укажите тег версии (например, `v1.1.0`).
4. Прикрепите собранный `ChattyWidgets.exe`.
5. Опубликуйте релиз.

## 👥 Модерация и одобрение виджетов от сообщества

Сторонние разработчики присылают виджеты через **Pull Request** в репозиторий [`ChattyWidgetsLibrary`](https://github.com/chattytoaster/ChattyWidgetsLibrary).

### Как проверить входящий Pull Request:
1. Откройте вкладку **Pull Requests** в репозитории `ChattyWidgetsLibrary`.
2. Робот GitHub Actions (`validate-pr.yml`) уже автоматически проверит:
   - Что ID виджета совпадает с GitHub-логином автора (`com.github.<username>.<name>`).
   - Что автор **не пытается** использовать имя `ChattyWidgets` или префикс `com.chatty.*`.
   - Что нет опасных расширений (`.exe`, `.dll`, `.bat`).
   - Что размер не превышает 25 МБ.
3. Перейдите во вкладку **Files changed** и оцените код виджета (нет ли скрытых вредоносных скриптов).
4. Если всё хорошо — нажмите **Merge pull request**!
5. **Всё остальное робот сделает сам**:
   - Запустится workflow `build-catalog.yml`.
   - Упакует виджет в `.chw`.
   - Автоматически проставит автора `@username` со ссылкой на его профиль.
   - Обновит `catalog.json`.
   - Через несколько секунд виджет появится в Магазине ChattyWidgets у всех пользователей!

## 🎨 Публикация официальных виджетов

Если вы создали новый официальный виджет от команды `ChattyWidgets`:

1. Поместите его в папку `widgets/com.chatty.<имя-виджета>/` в репозитории `ChattyWidgetsLibrary`.
2. Убедитесь, что в манифесте указан ID с префиксом `com.chatty.`.
3. Запустите скрипт сборки:
   ```bash
   python scripts/build_catalog.py
   ```
   Скрипт обнаружит ваш закрытый ключ, автоматически сгенерирует криптографическую подпись `[SIGNED OFFICIAL]` и упакует виджет.
4. Закоммитьте и запушьте изменения в `main`:
   ```bash
   git add .
   git commit -m "feat: add official widget com.chatty.<имя>"
   git push origin main
   ```
5. Приложение ChattyWidgets моментально признает виджет подлинным и наградит синим бейджем **`✦ Официальный`**.

## 🚨 Безопасность и защита от подделок

### Что происходит, если пользователь скачал сторонний `.chw` файл из интернета?
1. При перетаскивании файла `.chw` в окно приложения срабатывает метод [`SecurityService.InspectPackageFile()`](Core/Services/SecurityService.cs).
2. Если сторонний виджет пытается назваться `ChattyWidgets` или `com.chatty.*`, не имея вашей закрытой криптографической подписи:
   - Приложение выводит красное окно с предупреждением:
     > **ВНИМАНИЕ! Этот пакет пытается выдать себя за официальный виджет ChattyWidgets, но не имеет подлинной цифровой подписи разработчиков.**
   - Пользователь предупреждён о риске и может отменить установку.
3. В списке «Мои виджеты» такой виджет будет помечен красным бейджем:
   **`⛔ Подделка (не проверен)`**
   с подробным предупреждением об опасности.
4. Обычные сторонние виджеты без обмана получают честный янтарный статус:
   **`⚠ Сторонний виджет`**.
